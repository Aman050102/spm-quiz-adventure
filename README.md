# SPM Quiz Adventure

เกมตอบคำถามภาษาไทยสำหรับทบทวนวิชา Software Project Management

## เนื้อหา

- Agile, Scrum, Kanban, SAFe และ Hybrid
- Project Scoping, WBS, User Story และ Estimation
- Velocity, Burndown, Burn-up, CFD และ EVM
- Risk Management
- Automated Testing และ CI/CD
- Performance Testing ด้วย Grafana k6
- ISO/IEC 29110 และ ISO/IEC 25010

## วิธีเล่น

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ จากนั้นอ่านบททบทวนให้ครบ 7 บทเพื่อปลดล็อกเกม เกมจะสุ่มคำถาม 25 ข้อจากคลัง 70 ข้อ พร้อมหัวใจ 10 ดวง คะแนน คอมโบ และเฉลยทันที

ลำดับการใช้งาน: หน้าปก → ทบทวน 7 บท → เกม → สรุปผล การเล่นรอบใหม่จะเริ่มจากบททบทวนเสมอ

ไม่ต้องติดตั้ง Dependency และเล่นแบบออฟไลน์ได้
